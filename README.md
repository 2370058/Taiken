# よけゲー

マウス（スマホは指）で左右に動いて、上から落ちてくる玉をよけるゲームです。
時間がたつほど玉が速くなります。p5.js で書かれていて、全部で約80行です。

## 遊び方

- `index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）
- GitHub Pages で公開すると、URLを送るだけで友達のスマホでも遊べます

## コードの地図（sketch.js）

| ブロック | 場所 | Scratchでいうと |
|---|---|---|
| 準備 | `setup()` | 緑の旗が押されたとき |
| 自分 | `draw()` の前半 | ずっと：マウスの位置へ行く |
| 敵 | `draw()` の `enemies` まわり | クローンを作る・下に動く |
| 当たり判定 | `dist(...)` の if 文 | 〇〇に触れたなら |
| スコア・ゲームオーバー | `score` と `showGameOver()` | 変数・メッセージを送る |

## まずは改造してみよう

- 玉の色を変える：`fill(255, 90, 90)` の数字
- 玉が出る間隔を変える：`frameCount % 30` の `30`
- 速さを変える：`random(3, 6)` や `score / 500`
- 自分を絵文字にする：`circle(...)` を `text("🐱", player.x, player.y)` に

## 追加する機能の候補

やりたいものを選んで、担当者を決めてから作り始めましょう。

- [ ] ハイスコアを表示する（易しい）
- [ ] ライフ制にする：3回当たったら終了（易しい）
- [ ] アイテム：星を取るとボーナス点・数秒無敵（ふつう）
- [ ] 敵の種類を増やす：ジグザグに動く玉など（ふつう）
- [ ] 効果音を鳴らす（ふつう）

## GitHub Pages で公開する手順

1. このリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
3. 数分後に表示されるURLにアクセスすると遊べます
